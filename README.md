# PDF 书签目录工具 Android

**v0.1.9 正式版**。在 Android 平板上选择 PDF 和目录 JSON，生成包含完整多级书签的 PDF；对于已识别的享做笔记资源 PDF，还可同步享做自己的目录。无需无障碍服务，文件在本地处理，不要求联网或全盘访问权限。

## 功能

| 功能 | 使用结果 |
| --- | --- |
| PDF＋JSON 写入书签 | 支持 PC 版 `version: 1` 及 Jasminum 原生目录 JSON，完整保留多级结构 |
| 文件选择与粘贴路径 | 使用系统文件选择器，或粘贴享做复制的共享存储路径；首次使用需授权所在文件夹 |
| 两栏核对与页面预览 | 目录标题、目标页分栏显示；目录独立滚动，点击整行预览 PDF 实际目标页 |
| 页码映射 | 支持固定页码偏移、分段映射及直接指定 PDF 实际页码 |
| 同路径、同名替换 | 默认替换第1节选定的原 PDF；先生成、核验并备份，再切换文件名 |
| 另存副本 | 取消“直接替换原 PDF”后，自选保存位置，原 PDF 保留 |
| 享做目录同步 | 对已识别资源 PDF 同步享做独立目录，保留笔迹与其他配置 |
| 两种享做目录模式 | 默认保留已有目录并添加；也可全部替换，成功后不保留本次旧目录备份 |
| 仅同步目录 | 当前 PDF 已含与 JSON 相同的书签时，可只更新享做目录，不替换 PDF |
| 备份、恢复与统一清理 | 支持原 PDF 备份导出、未完成任务恢复；一个按钮清理本次关联的旧文件与备份 |
| 可选删除来源 JSON | 默认关闭；勾选后仅在 PDF 保存及所选同步成功、JSON 未变化且来源允许删除时执行 |
| 取消与返回 | 路径输入、文件选择和读取均可取消；取消选择保留此前选定的文件 |

当前长期维护范围为 **PDF＋JSON**。自动文字/OCR 提取目录、完整目录编辑工作台及批量处理尚未实现；完整对照见[功能范围](docs/FEATURES.md)。程序添加内部书签，不插入正文目录页、不修改页面标签。

## 快速使用

1. 下载上方 APK，在平板文件管理器中打开安装。升级时覆盖安装，保留应用数据。若系统提示安装来源授权，按系统提示允许该来源。
2. 准备原 PDF 和目录 JSON。要更新享做已有笔记，从其详情复制 **PDF 路径**，选定这个原资源文件；根目录里的“带目录”副本不是原笔记资源。
3. 在第1节选择文件或粘贴路径。首次使用共享路径或同路径替换时，授权包含文件的文件夹，例如“享做笔记/note”。文件权限与文件夹权限不同，粘贴路径本身不授予权限。
4. 点击“读取文件并预览目录”，滑动两栏目录并点击条目核对实际页面。如果 PDF 已有书签且需要更新，先勾选“替换PDF已有的整棵目录”，再核对并勾选“我已核对目录标题、层级和实际跳转页”。
5. 第3节默认同路径、同名替换，默认对已识别享做资源同步目录。展开“处理选项”可选择另存、享做目录模式及是否删除 JSON。同步享做前，先保存笔记并在系统设置中 **强行停止享做，不要清除数据**。
6. 点击“生成并替换原 PDF（同路径、同名）”，核对确认弹窗后执行；另存模式生成成功后会展开“更多操作与恢复”，点击“另存已生成的 PDF…”再选择保存位置。完成后重新打开 PDF／享做原笔记，核对目录、跳转页和原笔迹。
7. 确认正常后，如需删除剩余旧件，保存并停止享做，再点击“清理旧文件与备份”，核对完整清单后确认。此操作也会删除清单中的应用内恢复备份，之后不能用它们恢复。

详细授权、取消、JSON 示例、另存、故障处理与恢复步骤见[完整使用说明](docs/USER_GUIDE.md)。

## 两种目录与删除范围

第2节“替换PDF已有的整棵目录”控制 **PDF 内部书签**；第3节的两种模式控制 **享做自己的目录**，两者是独立选择。

| 第3节享做目录模式 | 原有手动目录 | 本次旧目录备份 |
| --- | --- | --- |
| 保留已有目录并添加新目录（默认） | 保留，并添加缺少的新项 | 保留，确认正常后可统一清理 |
| 用新目录替换全部已有目录 | 包括手动项在内的全部旧项被新 JSON 目录替换 | 新目录写入并核验成功后自动删除本次外部及内部目录副本，不能再用它们恢复 |

全部替换过程中仍使用必要事务副本；失败时保留恢复材料，不能先删除活动目录再写新目录。该自动删除仅针对本次两份旧目录副本，**PDF 备份不因此自动删除**。换输入文件或重新创建界面后恢复默认保留模式。

唯一的统一清理按钮只处理本工具成功记录关联、通过核验并列在清单中的旧 PDF、旧目录及对应应用内恢复备份。当前 PDF、活动 `catalog.json`、`catalog.json.temp`、笔迹、页面配置、其他笔记和原始 JSON 不在该清单中；JSON 删除由独立选项控制。未知或失去关联的旧文件不扫描、不猜删。详见[享做同步与恢复边界](docs/ENJOY_DIRECTORY.md)。

## 兼容与注意事项

- 已验收目标：HUAWEI MatePad Pro 12.2／MRO-W00／HarmonyOS 4.2.0，12 GB RAM、256 GB 存储、2800×1840。应用要求支持 APK 的 Android 8.0／API 26 或更高环境；HarmonyOS NEXT 不属于本版主路线。
- 享做同步依据享做 7.0.2 的已识别共享存储资源布局及页面映射，不保证其他享做版本或未知笔记格式自动兼容。未知结构、页码映射或文件变化时停止；普通 PDF 仍可只写标准书签。
- 替换或同步享做原资源前，保存笔记并强行停止享做；不要同时在享做修改该笔记。两次改名之间可能暂时没有原文件名，程序保存恢复记录；该流程不等于系统原子替换。
- 加密、密码保护、包含签名字段或无法安全处理的 PDF 会拒绝处理。目录页码从 **PDF 实际第1页**开始计数，须与印刷页码偏移区分。
- 未完成替换、同步或清理时，先按恢复提示处理，保留应用数据和相关文件。不要卸载或清除数据；清理删除的恢复备份、全部替换成功后删除的旧目录副本不能恢复。
- 发行 APK 沿用原签名，可覆盖升级。云端 CI 临时构建包不用于覆盖升级；签名和版本校验规则见[维护说明](docs/MAINTENANCE.md)。

## 源码、构建与维护

源码入口：`app/src/main`。使用 JDK 17、Android SDK 35 和项目自带 Gradle Wrapper：

```powershell
.\gradlew.bat assembleDebug lintDebug testDebugUnitTest --no-daemon --console=plain
```

也可使用 `scripts/build.ps1 -ToolingRoot '<含 jdk 和 sdk 的工具目录>'`。标准输出在 `app/build/outputs/apk/debug/`；安装后的平板程序不依赖电脑上的源码或构建缓存。
