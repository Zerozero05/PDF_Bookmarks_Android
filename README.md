# PDF 书签目录工具 Android

选择 PDF 和目录 JSON，生成包含完整多级书签的 PDF；已识别的享做笔记资源 PDF 还可同步享做目录。PDF处理在本地完成，无需无障碍服务或全盘访问权限；更新功能仅连接本项目GitHub。

**本地试用候选 v1.4.0／code17（2026-10-24，未公开发布）**：完成12项流程与界面优化，生成前先只读检查，明确区分待保存、部分成功和待恢复；未完成步骤可就地续办，保存后目录失败保留绑定最终PDF的核对草稿，重开须重读核验并重新确认。核对与差异定位更直接，JSON可选删除失败可明确结束该步骤并保留文件。全部旧功能保留，不新增OCR、编辑、批量、云端或依赖。最终离线构建通过，331项JUnit中328通过、0失败／错误、3项缺旧样本跳过，lint0错误／25警告；原生组件编译通过，ADB无设备，本轮实机尚未运行。见[本次完整记录](CHANGELOG.md#v1-4-0)、[候选使用方法](docs/USER_GUIDE.md#v140-流程与界面试用)及[D69–D80待验项](docs/DEVICE_ACCEPTANCE.md#v140-流程与界面验收)。以下公开下载仍为v1.3.0。

## 功能

| 功能 | 使用结果 |
| --- | --- |
| PDF＋JSON 写入书签 | 兼容 PC 版 `version: 1` 和 Jasminum 原生目录，保留多级结构；支持固定偏移、分段映射及直接指定 PDF 实际页 |
| 文件选择与粘贴路径 | 默认在应用内浏览已授权位置，固定显示“取消选择”；保留系统来源和粘贴路径，输入及读取可取消 |
| 授权位置管理 | 在授权根左滑、菜单或选择模式查看详情／复制路径／刷新，单项或批量移除本工具的授权；不删除文件 |
| 两栏核对与预览 | 标题与目标页分栏，目录独立滚动；点击整行预览目标页 |
| 搜索、折叠与页码试算 | 标题搜索、层级折叠及定位当前项；整体／分段试算后明确应用；最终仍写入完整目录 |
| 预览与外观 | 缩放／全屏、可拖动分栏及主题／字号／间距；当前任务不因外观调整重新开始 |
| 核对草稿 | 自动保存调整页码、搜索、折叠和位置；重新读取文件并验证内容与原树后恢复，须重新勾选核对 |
| 诊断与差异 | 导入问题可定位、复制；生成前只读对比 PDF 书签和享做目录，区分新增／删除／变化，不代替写入校验 |
| v1.4.0候选流程 | 保存条件预检、准确的待保存／待恢复状态、未完成步骤续办；差异点选定位、浏览页与目标页提示、随窗口和字体调整核对区 |
| 分享与简洁操作 | 接受来源应用分享的 PDF／JSON，经确认才选入；长按目录看完整详情，返回逐层退出，结果自动定位 |
| 替换或另存 | 默认同路径同名替换，先生成、核验并备份；也可取消替换后另存副本 |
| 享做目录同步 | 默认保留已有目录并添加，也可全部替换；PDF 已有匹配书签时可仅同步目录 |
| 自动检测与安装更新 | 默认启动／前台每天最多检查一次GitHub最新正式版，可关闭或手动检查；确认下载并核验后交给系统安装，保留应用数据 |
| 备份与清理 | 支持原 PDF 备份导出、未完成任务恢复及按清单清理；删除来源 JSON 默认关闭 |

当前维护范围为 **PDF＋JSON**，只添加内部书签，不插入正文目录页、不修改页面标签。OCR／自动提取、完整编辑工作台及批量处理尚未实现，见[功能范围](docs/FEATURES.md)。

## 快速使用

1. 下载并打开 APK；升级时直接覆盖安装，保留应用数据。若系统询问安装来源权限，按提示允许。
2. 在 PDF／JSON 区域分别“浏览文件”或“粘贴路径”。应用内列表的右上角始终有“取消选择”；首次授权后可浏览文件夹，“更多文件来源”保留系统入口。更新享做原笔记时，使用详情中的 **PDF 路径**，不要选择根目录里的“带目录”副本；同路径替换须授权原文件夹，粘贴路径不等于获得授权。系统来源界面仍由设备系统提供。
3. 点击“读取文件并预览目录”，核对标题、层级和实际跳转页，再勾选核对确认。v1.1.1可搜索、折叠、缩放预览，在“更多 → 页码调整…”试算并抽查；明确应用后重新勾选核对。已有 PDF 书签默认跳过；确需覆盖时先勾选“替换PDF已有的整棵目录”。页码从 **PDF 实际第1页**计数。
4. 第3节默认同路径同名替换，并对已识别的享做资源同步目录。在“处理选项”选择另存、享做目录模式或 JSON 删除；同步享做前先保存笔记，在系统设置中 **强行停止享做，不要清除数据**。
5. 点击生成，核对确认范围后执行。v1.1.1的底部主按钮随步骤提示读取、核对、生成或打开，结果卡片分别显示 PDF、保存、享做目录、JSON 与旧件状态；“查看详情与文件位置”可复制具体结果。另存模式生成后，使用保存已生成 PDF 的入口选择位置。重开 PDF／享做原笔记，检查目录、跳转和原笔迹。
6. 确认正常后再决定是否清理；先保存并停止享做，点击“清理旧文件与备份”，核对完整清单后确认。可保留备份以便恢复。

JSON 示例、授权、仅同步、故障处理与恢复步骤见[完整使用说明](docs/USER_GUIDE.md)。

## 默认值、删除与恢复

PDF 内部书签和享做目录是独立选择：第2节控制是否覆盖整棵 PDF 书签；第3节控制享做的目录树。

| 选项 | 默认值与影响 |
| --- | --- |
| 直接替换原 PDF | 开启；成功后保留同目录旧 PDF 和应用内 PDF 备份，需明确清理才删除 |
| 替换后同步享做目录 | 开启；仅处理已识别的资源 PDF，普通 PDF 不猜测所属笔记 |
| 享做目录处理方式 | 保留已有目录并添加新项；全部替换会覆盖手动项，新目录核验成功后自动删除本次外部旧目录与内部目录副本，PDF 备份保留 |
| 成功后删除来源 JSON | 关闭；开启后仍须保存、所选同步及相关清理成功，JSON 未变化且有删除权限；仅同步入口始终保留 PDF 和 JSON |

换输入或重新创建界面会恢复默认保留目录模式；换输入也会关闭 JSON 删除。v1.1.1的主题、字号、间距或窗口布局切换在当前界面应用，不重新创建任务，不替用户更改目录模式或 JSON 删除选择。全部替换仍先用事务副本保障写入，失败保留恢复材料，不先删活动目录再写新目录。

统一清理只删除成功记录关联、核验合格且列明的旧 PDF、旧目录及对应应用内恢复备份，**删除后不能用它们恢复**。当前 PDF、活动 `catalog.json`／`catalog.json.temp`、笔迹、页面配置、其他笔记及来源 JSON 均保留；未知或失去关联的旧件不扫描、不猜删。JSON 仅按上述独立选项处理。

遇到未完成替换、同步或清理，先按恢复提示操作，保留应用数据和相关文件；不要卸载、清数据或盲删配置。备份导出、恢复消失 PDF、继续清理和保留剩余文件的边界见[享做同步与恢复](docs/ENJOY_DIRECTORY.md)。

## 兼容与验证

- 已验收目标：HUAWEI MatePad Pro 12.2／MRO-W00／HarmonyOS 4.2.0（12 GB／256 GB，2800×1840）；要求支持 APK 的 Android 8.0／API 26 或更高环境。HarmonyOS NEXT 不属于本版主路线。
- 享做同步适配 7.0.2 的已识别共享存储资源布局及页面映射。未知结构、映射或文件变化时停止；加密、密码保护、含签名字段或无法安全处理的 PDF 拒绝处理。文件提供者须支持所需读写、创建及改名，否则使用另存；两次改名是可恢复流程，不等于系统原子替换。
- v0.1.9 已获目标设备总体用户验收；不据此推断逐项故障演练、云同步、其他设备或享做版本均已验证。历史本地／云端检查及跳过项见 [VALIDATION](VALIDATION.md) 和[设备验收记录](docs/DEVICE_ACCEPTANCE.md)。

## 源码、构建与维护

源码入口：`app/src/main`。使用 JDK 17、Android SDK 35 和项目自带 Gradle Wrapper：

```powershell
.\gradlew.bat assembleDebug lintDebug testDebugUnitTest --no-daemon --console=plain
```

也可使用 `scripts/build.ps1 -ToolingRoot '<含 jdk 和 sdk 的工具目录>'`；APK 输出在 `app/build/outputs/apk/debug/`。详细参数和真实样本回归见[源码与构建](docs/USER_GUIDE.md#源码与构建)；[维护说明](docs/MAINTENANCE.md)涵盖版本、签名与文档维护，[发布约定](docs/GITHUB_PLAN.md)规定产物命名，[现行需求](docs/REQUIREMENTS.md)记录功能边界。

发行 APK 沿用原升级签名，可覆盖安装；云端 CI 临时签名包不用于覆盖升级。已安装应用不依赖电脑源码或构建缓存。原标签及5个发行附件保留首次发布内容；源码 ZIP 内文档属于发布时版本，最新说明以 `main` 分支为准。

项目采用 [GNU AGPL v3](LICENSE)，PDFBox Android、Gson 等依赖见[第三方说明](THIRD_PARTY_NOTICES.md)。发行附件含 APK、完整可编辑源码包及 SHA-256 清单，源码与对应标签一致。
