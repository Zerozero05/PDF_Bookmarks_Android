## 首版功能与边界

v0.1.9 在 Android 平板上提供 PDF + 目录 JSON 的内部书签生成流程。支持 PC `version:1` 目录、Jasminum 原生目录、多级层次、固定偏移及分段页映射。目录核对以标题与目标页独立两栏显示，固定表头，标题保留缩进并可换行，页码靠右；整行可点击，目录独立滑动及旁边 PDF 页面预览保留。已有书签默认跳过，明确替换时覆盖整棵旧目录。支持粘贴已授权共享存储路径，路径和读取过程可取消返回，不自动反复打开授权选择器。

默认保持原路径与原名，生成前仍需确认；授权原文件夹后，先创建并核验暂存 PDF，再将原件改名为备份、新文件改为原名。支持恢复记录、备份导出和从备份恢复消失原件。对严格识别的享做资源PDF默认备份并合并其目录，保留手动目录、根字段、笔迹与其他配置；PDF已有相同书签时可仅同步目录。未知结构、映射或变化会停止。只有PDF及所选同步成功后才可选删除JSON。单笔记目录/跳转/笔迹实测成功，正式APK的设备提供者、保存再打开与云同步仍待验证。

第3节折叠处理选项与更多/恢复操作，保留原有功能。享做目录默认保留旧项并添加新项，也可选择全部替换，包括原手动项；全部替换写入并核验成功后，先显示本次旧目录两份副本的完整路径，再自动删除外部旧目录及内部目录恢复副本，不保留它们。事务过程及失败保留必要恢复材料，不能先删后写；失败可按持久进度续行或归档后保留剩余文件并结束清理。PDF备份、默认保留并添加模式、JSON选项及其他功能不变；完全相同目录树不重写、不删除历史目录关联。

成功后先核对PDF、享做目录/跳转及笔迹，再保存并停止享做；一个“清理旧文件与备份”按钮仍先展示完整清单，确认后统一删除记录关联的剩余外部旧PDF/目录和应用内恢复备份。清理后不能靠这些备份恢复，当前活动文件/笔迹/其他配置保留；未知或旧版失去关联的备份不扫描。整批先校验、外部先删/内部最后删，记录持久化，中断可重试。除上述全部替换目录副本外，不在保存成功时自动清理其他备份。

本版尚未移植 PC 的文字/OCR自动识别、批量处理及完整目录编辑工作台。应用不使用无障碍服务、网络或全盘访问权限。构建及本地检查结果将在发布前写入独立验证记录，目标 MatePad Pro 的安装、保存与享做显示由用户试用确认。
